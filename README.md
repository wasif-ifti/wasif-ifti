# Hey, I'm Wasif 👋

CS student at **Drexel University** in Philly. I like building things for the web, poking around in Unix, writing C that (usually) doesn't segfault, and lately, teaching my car to tell me when something's wrong.

- 🚗 Building **[OBD2 Anomaly Detection](https://github.com/wasif-ifti/OBD2-Anomaly-Detection)**, a Python ML project that learns what "normal" looks like for my Lexus hybrid and flags problems before the check engine light comes on
- 🐉 Built **[The Dragon's Nest](https://the-dragons-nest.netlify.app/)**, a campus map for Drexel students, with a team of four
- ✍️ Used to write about cybersecurity and AI as a contributing columnist at *The Asian Age*
- 🌱 Currently going deeper into machine learning and algorithms
